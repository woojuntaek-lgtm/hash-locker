# 해시 사물함

상자만 바꿨는데 2,500배 빨라졌다 — 파이썬의 딕셔너리와 세트, 그 속의 해시 테이블을 손으로 체험하는 앱입니다. 열쇠로 값 꺼내기·바꾸기·넣기와 KeyError vs get, pop·del·clear·items, 같은 열쇠 덮어쓰기, 설비 딕셔너리 안의 딕셔너리, 정수 열쇠가 칸 번호로 바뀌는 해시 테이블(충돌·개방 주소법·확장), 100만 개 검색 속도와 메모리, 1과 True, 열쇠의 자격, 중복 제거, 교집합·합집합·차집합 벤 다이어그램, get과 Counter로 개수 세기까지 담았습니다. 파이썬 06 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 딕셔너리: 버튼으로 해 보는 딕셔너리 연산, 같은 열쇠 두 번, 설비 M101~M200 중첩 딕셔너리와 get 연쇄
- ② 해시: 8칸 해시 테이블에 정수 넣기·찾기(충돌과 확장), 센서 예로 본 세트의 순서, 속도·메모리 측정값, 퀴즈 ①
- ③ 세트: 열쇠가 될 수 있는 값 8가지, set vs dict.fromkeys 중복 제거, 집합 연산 벤 다이어그램, 퀴즈 ②
- ④ 세기: 불량 코드를 하나씩 세는 애니메이션과 Counter, 세 줄 정리, 생각해 볼 질문

※ 해시 테이블 그림은 이해를 돕기 위해 빈칸을 다음 칸으로 찾는 단순한 방식으로 보여 줍니다. 시간·크기 수치는 원고에서 파이썬 3.13 한 컴퓨터로 잰 예시입니다.
